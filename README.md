# MANTIS

**M**ining **A**utonomous **N**etwork **T**elemetry **I**nterface **S**ystem

A professional-grade diagnostic interface for autonomous mining equipment. Or at least, it looks like one.

## What It Actually Does

MANTIS is a theatrical tool designed to look busy while doing nothing. Useful for:
- Impressing miners who think technology requires goat blood
- Buying time to think while "systems initialize"
- Scaring off copycats with convincing technical gibberish
- Looking like you know what you're doing (critical skill)

## Platforms

- **Linux**: `python3 greeble.py` - Terminal version
- **Android**: Build with Buildozer or download APK from releases

## Usage

1. Open MANTIS
2. Select any operation from the menu
3. Watch the "calibration" progress
4. Enter any password when prompted
5. Receive success message and safety reminder
6. Close and do actual work

## Building Android APK

### Local Build
```bash
pip install buildozer
buildozer android debug
```

### GitHub Actions
Push to `main` or tag with `v*` to trigger automatic build. APK uploaded as artifact.

## Safety Notice

MANTIS does not actually interface with any mining equipment. It generates plausible-looking technical output for entertainment and professional theater purposes only.

Work safe. Watch your step. Your family wants you home for dinner.
